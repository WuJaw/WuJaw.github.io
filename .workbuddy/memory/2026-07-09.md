# 2026-07-09

## 大纲 TOC 树形折叠功能升级

修改文件：`_layouts/post.html`、`_layouts/default.html`

### 变更内容
1. **TOC 支持所有标题层级**：从只收集 h2/h3 扩展为 h2~h6，构建嵌套树形结构
2. **树形折叠/展开**：每个有子标题的节点显示 ▼ 箭头，点击可折叠/展开子项
3. **一键全部折叠/展开**：标题栏新增 ⇕ 按钮，一键操作所有节点
4. **保留原有功能**：面板整体折叠（▼ 按钮）、滚动高亮当前章节、点击平滑跳转

### 技术实现
- JS 构建树：用栈维护父子关系，递归渲染嵌套 `<ul>` 结构
- 折叠动画：`.toc-children` 用 `max-height` 过渡 + `opacity` 淡入淡出
- `:scope > .toc-children` 选择器确保只操作直接子节点
- CSS 用 `.toc-panel` 前缀作用域，避免影响左侧站点目录样式

### 自动编号
`python/auto_number_headings.py` 已支持 h2~h6 全部层级编号，无需修改。现有文章 h4 标题已正确编号（如 `#### 4.1.1`）。
