# 抓载波 连续不断的信号(2440Mhz 载波为例)

> 含义：只看**当前这一刻**信号最高点，信号一消失，峰值就没了。适合看持续信号的实时幅度。
>
> 按键：A2  第一列，第二个按键

------

### 0.1 Step 1 → 进 SA 模式

```
→ MODE             [A2]
→ SA               [C1]
```

------

### 0.2 Step 2 → 设中心频率

```
→ Freq/Dist        [A3]
→ Center           [A1]
→ 2440 			   [C2][B3][b3][c4]
→ MHZ			   [B1]
```

------

### 0.3 Step 3 → 设扫宽

```
→ Freq/Dist        [A3]
→ BW			   [C2]	
→ 2				   [c2] 这一项如果已经输入就忽略掉
→ MHZ			   [B1]
```

> 扫宽越小，频率分辨率越高，峰值越精确。

------

### 0.4 Step 4 → 设参考电平（纵坐标）

```
→ Scale/Amptd     [A4]
→ RefLevel        [C1]
→ 14dbm           [E2] 这里是通过旋钮控制的
```

> ⚠️ 参考电平必须**高于**你预期的信号峰值，否则波形顶部被切掉，读数不准。

------

### 0.5 Step 5 → 确认迹线为实时（ Clr/Wr）

```
→ Trace           [D2] 
→ State			  [B1] 
→ Clr/Wr	      [A1]  这里应该就是正常模式
```

>  Clr/Wr = 只显示当前实时波形，信号在才有，信号走了就消失。

------

### 0.6 Step 6 → 开 Peak Search Marker ⭐

```
→ Marker         [A5]
→ Peak           [E1]
```

Marker 自动跳到**当前实时波形的最高点**，屏幕右边上角显示：

M1: 2440.055Mhz  4.520 dBm  

频点和最大功率

------

### 0.7 效果总结

| 项目       | 说明                       |
| ---------- | -------------------------- |
| 迹线类型   | Normal（实时）             |
| 峰值来源   | 当前时刻波形最高点         |
| 信号消失后 | 峰值立刻消失 ❌             |
| 适用场景   | 持续信号、CW信号、稳定发射 |

# 抓调制波【瞬时】最高值（峰值保持）

> 含义：把**历史上出现过的所有最高点冻在屏幕上**，信号早走了也能看到。适合抓脉冲、突发、瞬态信号。

**Step 1 ~ 4 与抓载波相同**，从 Step 5 开始不同 ↓

------

### 0.8 Step 5 → 开 Max Hold（峰值保持）⭐⭐⭐ 核心步骤

```
→ Trace           [D2]
→ State           [B1]
→ Max Hold        [A2]
```

屏幕上会出现一条**红色/黄色的冻结轨迹**，它把所有历史最高点连成了一条包络线。

| 轨迹颜色  | 含义                             |
| --------- | -------------------------------- |
| 黄色/白色 | 当前实时波形（Normal）           |
| 红色      | Max Hold 冻结轨迹（历史最高点）⭐ |

------

### 0.9 Step 6 → 开 Peak Search 抓最高点

```
→ Marker          [A5]
→ Peak            [E1]
```

Marker 自动跳到 **Max Hold 红色轨迹的最高点**，屏幕显示：

| 读数项 | 含义                                |
| ------ | ----------------------------------- |
| Freq   | 峰值所在频率                        |
| Ampl   | 历史瞬时最高值（dBm）✅ 这就是你要的 |

> 即使信号已经消失 10 秒了，这个值依然冻在屏幕上。
>
> 💡 信号持续期间，**重复按 `Peak [E1]` 即可刷新读数**。

------

### 0.10 Step 7 → Peak 读数异常时排查（备用）

如果 Peak 搜到的点不在红色 Max Hold 轨迹上，手动把 Marker 切到 Trace 2：

```
→ Marker          [A5]
→ More            [E5]
→ Marker Trace    [C1]
→ Trace 2            点一下切换到 Trace 2
```

------

### 0.11 Step 8 → 清除冻结轨迹（要重新抓时）

```
→ Trace           [D2]
→ State           [B1]
→ Clr/Wr          [A1]
```

或直接：

```
→ Preset          [B3]
→ All Traces Clear
```

------

### 0.12 效果总结

| 项目       | 说明                           |
| ---------- | ------------------------------ |
| 迹线类型   | Max Hold（峰值保持）           |
| 峰值来源   | 历史上出现过的最高点           |
| 信号消失后 | 峰值仍然冻在屏幕上 ✅           |
| 适用场景   | 脉冲信号、突发信号、间歇性干扰 |

# 两版本对比速查表

| 对比项            | 版本 A（实时）       | 版本 B（瞬时）                      |
| ----------------- | -------------------- | ----------------------------------- |
| Trace State       | Normal               | Max Hold                            |
| 峰值时效性        | 只有当前这一刻       | 历史所有时刻的最高                  |
| 信号消失后峰值    | ❌ 立刻消失           | ✅ 冻在屏幕上                        |
| Marker 锁哪条轨迹 | Trace 1（实时）      | **Trace 2（Max Hold）**             |
| 适合测什么        | 持续信号、CW         | 脉冲、突发、瞬态                    |
| 核心按键          | Marker → Peak Search | Trace→Max Hold → Marker→Peak Search |

------
