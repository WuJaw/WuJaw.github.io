## 1 概述

本手册面向产线操作人员，介绍如何使用「CH592 Part No 烧录工具」配合 WCH 官方 ISP 工具实现芯片的**自动序列号烧录**。

每次成功烧录后，序列号自动 +1，无需人工修改，支持流水号从 00001 到 99999 的连续递增。

---

## 2 环境准备

### 2.1 硬件要求

| 项目 | 要求 |
|------|------|
| 电脑 | Windows 10/11，已安装 Python 3.8+ |
| 烧录器 | WCH-Link 或 USB 转串口模块 |
| 芯片 | CH592F 或其他 CH57x/CH59x 系列 |

### 2.2 文件清单

确保工作目录中有以下文件：

```
烧录工作目录/
├── wch_isp_gui_enhanced.py    ← 本工具（Python 脚本）
├── part no.bin                ← 序列号文件（工具自动生成）
└── config.json                ← 配置文件（工具自动生成）
```

> **注意**：`wch_isp_gui_enhanced.py` 和 `WCHISPTool` 可以放在不同目录，但建议放在同一文件夹方便管理。

## 4 参数设置

### 4.1 设置前缀

**前缀**代表产品批次号，固定 3 位十六进制字符（0-9、A-F）。

- 点击「前缀」输入框，输入 3 位字符，如 `87F`
- 输入框会自动限制只能输入合法十六进制字符
- 如果输入超过 3 位，会自动截断

### 4.2 设置起始号码

**起始号码**是流水号的起始值，5 位十进制数字（00000 - 99999）。

- 点击「起始号码」输入框，输入数字，如 `1`
- 工具会自动补零显示为 `00001`
- 流水号超过 99999 后会自动回到 00000

### 4.3 查看当前值预览

设置好前缀和起始号码后，「当前值预览」会实时显示组合后的完整序列号：

```
前缀: 87F
起始号码: 1
当前值预览: 0x87F00001
```

这个预览值就是实际写入芯片的 Part No。

### 4.4 字节序选择

字节序决定 `part no.bin` 文件中的 4 字节排列顺序：

| 选项 | 文件内容（以 0x87F00001 为例）| 适用场景 |
|------|-------------------------------|---------|
| **不勾选**（大端）| `87 F0 00 01` | WCH ISP 工具默认方式 |
| **勾选**（小端）| `01 00 F0 87` | 特殊固件需求 |

> **默认不勾选即可**，WCH ISP 工具读取 `part no.bin` 使用的是大端序。

## 5 WCH ISP 工具配置

### 5.1 打开 ISP 工具

双击运行 `WCHISPTool_CH57x-59x.exe`（WCH 官方烧录工具）。

### 5.2 设置 Part No 文件路径

1. 在 ISP 工具中找到 **Part No 文件** 或 **用户数据** 设置项
2. 点击「浏览」按钮
3. 选择本工具生成的 `part no.bin` 文件
4. 确认设置

> **重要**：`part no.bin` 文件由 Python 工具自动生成和更新，不需要手动修改。

### 5.3 确认芯片型号和接口

- 选择正确的芯片型号（如 CH592F）
- 选择烧录接口（USB 或串口）
- 设置好波特率（串口烧录时）

## 6 烧录操作流程

### 6.1 标准单人操作（推荐）

1. **放置芯片** — 将芯片放入烧录座或连接好烧录线
2. **ISP 工具点击下载** — 在 WCHISPTool 中点击「下载」按钮
3. **等待烧录完成** — 观察 ISP 工具的"下载记录"区域，出现「成功：1」表示完成
4. **取出芯片** — 烧录完成后取下芯片，放入下一个
5. **重复步骤 1-4** — 下一个芯片自动使用新序列号

> **注意**：Python 工具会每 500ms 自动检测 ISP 工具的「成功」次数。只要成功次数增加，序列号就会自动 +1。不需要手动修改任何参数。

### 6.2 快速连续烧录

如果烧录速度较快，可以：

1. 保持 Python 工具和 ISP 工具**同时打开**
2. 每次烧录成功后，观察 Python 工具的「当前值预览」是否变化
3. 如果变化了，说明自动累加成功，继续烧录下一个芯片
4. 如果没有变化，检查「窗体监控」区域是否有 ISP 工具的文字输出

## 7 验证烧录结果

### 7.1 检查 part no.bin 内容

如果想确认当前序列号的二进制内容，可以用以下命令查看：

```bash
python -c "import sys; f=open('part no.bin','rb'); print(f.read().hex().upper())"
```

例如前缀 `87F`、起始号码 `1`、大端序时，输出应为：

```
87F00001
```

### 7.2 验证自动累加

在 Python 工具的「窗体监控」区域，应该能看到类似以下内容：

```
[找到窗口: WCHISPTool_CH57x-59x]
[窗口类名: ...]
```

如果看到「成功：X」相关文字，说明监控正常。每次成功数字增加时，「当前值预览」会自动更新。

## 8 注意事项

### 8.1 不要手动修改 part no.bin

`part no.bin` 由 Python 工具自动维护，手动修改可能导致序列号混乱。

### 8.2 不要关闭 Python 工具

烧录过程中请保持 Python 工具运行。关闭后自动累加功能失效，需要重新启动并重新设置参数。

### 8.3 窗体监控读不到文字怎么办

如果「窗体监控」区域只显示窗口标题，没有下载记录内容：

- 确认 ISP 工具已经打开且窗口可见
- 确认 ISP 工具标题包含 `WCHISPTool` 或 `CH57x-59x`
- 尝试将 ISP 窗口置于前台（点击一下 ISP 窗口）
- 如果仍然读不到，说明 ISP 工具的下载记录是自绘控件，此时需要**手动记录烧录次数**，在 Python 工具中点击「起始号码」手动 +1

### 8.4 断电或异常退出

如果电脑断电或 Python 工具意外关闭：

1. 重新启动 Python 工具
2. 查看「当前值预览」显示的值
3. 如果值不对，手动修改「起始号码」为正确的下一个流水号
4. 继续烧录

### 8.5 流水号归零

当流水号达到 99999 后，下一次会自动回到 00000。如果不需要归零，请在接近 99999 时手动更换前缀（批次号）。

## 9 常见问题

### 9.1 Q1：启动时提示缺少 tkinter

**现象**：运行脚本时报错 `ModuleNotFoundError: No module named 'tkinter'`

**解决**：Python 安装时未勾选 Tcl/tk 支持。重新安装 Python，安装界面勾选「tcl/tk and IDLE」。

### 9.2 Q2：ISP 工具提示找不到 part no.bin

**现象**：ISP 工具中选择 Part No 文件时提示文件不存在

**解决**：
1. 先运行一次 Python 工具，会自动生成 `part no.bin`
2. 或者在 Python 工具中任意修改一下前缀或起始号码，触发文件生成

### 9.3 Q3：烧录后芯片里的序列号不对

**现象**：读取芯片 Part No 发现值和预览不一致

**解决**：
1. 检查「字节序」设置，确认和 ISP 工具的预期一致
2. 检查 ISP 工具中设置的 Part No 文件路径是否正确
3. 重新生成 `part no.bin`（修改一下起始号码再改回来）

### 9.4 Q4：成功烧录但序列号没自动增加

**现象**：ISP 工具显示成功，但 Python 工具的当前值没变

**解决**：
1. 检查「窗体监控」区域是否有 ISP 工具的文字输出
2. 如果没有输出，说明自绘控件读不到，需要手动修改起始号码
3. 如果有输出但没有「成功：X」字样，确认 ISP 工具的语言是否为中文

### 9.5 Q5：如何批量烧录同一个序列号

**现象**：希望多个芯片使用同一个 Part No，不要自动累加

**解决**：不启动 Python 工具，直接用 ISP 工具烧录固定的 `part no.bin` 即可。Python 工具只在需要自动累加时才使用。

## 10 附录

### 10.1 Part No 格式速查

| 前缀 | 起始号码 | 组合值 | 说明 |
|------|---------|--------|------|
| 87F | 1 | 0x87F00001 | 第 1 个芯片 |
| 87F | 2 | 0x87F00002 | 第 2 个芯片 |
| 87F | 10 | 0x87F0000A | 第 10 个芯片（注意：后缀是十进制，组合值是十六进制）|
| 87F | 99999 | 0x87F1869F | 第 99999 个芯片 |
| 880 | 0 | 0x88000000 | 更换批次后的第 1 个芯片 |

### 10.2 目录结构示例

```
D:\产线烧录\
├── wch_isp_gui_enhanced.py       ← Python 工具
├── part no.bin                    ← 序列号文件
├── config.json                    ← 配置文件
├── WCHISPTool_CH57x-59x.exe       ← WCH 官方烧录工具
└── 固件\
    └── firmware.hex               ← 芯片固件（如有）
```
