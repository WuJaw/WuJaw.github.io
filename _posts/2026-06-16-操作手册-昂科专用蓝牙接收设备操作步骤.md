## 1 x shell 用作串口调试助手

### 1.1 下载X shell 免费版本

+ X shell免费版本下载：[家庭/学校免费 - NetSarang Website (xshell.com)](https://www.xshell.com/zh/free-for-home-school/)

![photo](https://i-blog.csdnimg.cn/blog_migrate/09eead60eb8f16a00e4bc9d40bc042d3.png#pic_center)

该软件主要是用来做串口调试助手的，当然你有其他的也可以尝试其他的。

### 1.2 安装X shell

+ 打开文件

![在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/5995ac885a7b7ddd0fdf20738e0666da.png)

+ 点击下一步

![photo](https://i-blog.csdnimg.cn/blog_migrate/ad48b681ee88f8eb9251243e59edf638.png#pic_center)

+ 勾选协议，点击下一步

![photo](https://i-blog.csdnimg.cn/blog_migrate/93ffcb1ffbdcdf397287e976e2538dd1.png#pic_center)

+ 可以修改安装位置，我们这里选择默认直接下一步.

![photo](https://i-blog.csdnimg.cn/blog_migrate/59f95d00e2af57a783b906cb36f3a7f3.png#pic_center)

+ 点击软件安装

![photo](https://i-blog.csdnimg.cn/blog_migrate/7644cdd65351cac9c390132bbcb78dc7.png#pic_center)

+ 完成安装，点击完成

![photo](https://i-blog.csdnimg.cn/blog_migrate/4eed4721f14ec763757f5fc3d653b1e1.png#pic_center)

+ 如果提醒需要注册我们可以选择注册一下.

![photo](https://i-blog.csdnimg.cn/blog_migrate/efd9f017e3c4d21364f3642d0695b8d2.png#pic_center)

+ 点击后来进入界面，选择新建会话

![photo](https://i-blog.csdnimg.cn/blog_migrate/2a718d2bf190910d7c108939109bed40.png#pic_center)

+ 首先协议选择串口协议 

![photo](https://i-blog.csdnimg.cn/blog_migrate/ba52160ed92c6d48e137b081171817c5.png#pic_center)

+ 再点击串口

![photo](https://i-blog.csdnimg.cn/blog_migrate/a8db8e6a032eb95c91d0dc11a024d3b1.png#pic_center)

+ 这些串口的参数，相信大家都很熟悉了，我们直接按照自己的实际的串口进行选择即可。

![photo](https://i-blog.csdnimg.cn/blog_migrate/e348139d31e91c3f4c2369baab199012.png#pic_center)

+ 最后点击确定。

![photo](https://i-blog.csdnimg.cn/blog_migrate/5aceff0548242c020cc03d86d6478646.png#pic_center)

+ 点击连接

![photo](https://i-blog.csdnimg.cn/blog_migrate/bf14ae72a6848256b1ce58b4476d1b5a.png#pic_center)

+ 连接上 X shell。

<img src="/assets/image-20260616151159107.png" alt="image-20260616151159107">

+ 点击黑框，输入快捷键 ctrl+ q 就可以开始获取到数据了

<img src="/assets/image-20260616151334947.png" alt="image-20260616151334947">
