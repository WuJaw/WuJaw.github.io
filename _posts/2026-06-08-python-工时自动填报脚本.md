## 1 背景

公司工时系统是一个 Vue 3 + Element Plus 的 Web 应用，日常需要每天手动登录填报工时内容。由于工作内容已经写在周报 Excel 中，重复填写效率很低，于是写了 Python 脚本自动完成：

- 从周报 Excel 读取每天的工作内容和项目编码
- 自动提交到工时系统

## 2 接口分析

### 2.1 抓包方式

由于工时系统在内网，无法通过外部工具直接访问。通过浏览器 F12 Console 注入拦截器来捕获请求：

```javascript
// 拦截 XHR 请求的 URL 和响应
(function(){
  var origOpen = XMLHttpRequest.prototype.open;
  var origSend = XMLHttpRequest.prototype.send;
  XMLHttpRequest.prototype.open = function(){
    var xhr = this;
    xhr.addEventListener('readystatechange', function(){
      if(xhr.readyState === 4){
        console.log('[POST] ' + xhr._u + ' => ' + xhr.status);
        console.log('  Response: ' + xhr.responseText.substring(0, 500));
      }
    });
    origOpen.apply(this, arguments);
    xhr._u = arguments[1];
  };
  // 拦截请求体
  XMLHttpRequest.prototype.send = function(body){
    console.log('Body: ' + body);
    return origSend.apply(this, arguments);
  };
  console.log('Interceptor started');
})();
```

### 2.2 关键接口

通过拦截发现三个核心接口：

| 接口 | 说明 | 请求体 |
|------|------|--------|
| `POST /api/dailyReport/add` | 新建日报 | 数组格式 |
| `POST /api/dailyReport/update` | 更新日报 | 对象格式，需带 id |
| `POST /api/dailyReport/list` | 查询日报列表 | 分页参数 |

新建日报的请求体结构（数组内每个元素）：

```json
{
  "key": "000",
  "workDuration": "8",
  "workMatters": "1.协助组装蓝牙设备\n",
  "workDate": "2026-03-06",
  "projectId": 194,
  "workOvertime": "",
  "userCompellation": "吴潇",
  "isOverTime": false,
  "taskId": 818,
  "taskList": [...],
  "projectName": "昂科物联网定位平台系统V3.0",
  "taskName": "开发测试",
  "projectType": 1,
  "projectCode": "RD240009",
  "projectUserName": "蒋博",
  "userId": 111,
  "auditing": 0
}
```

> 注意：`add` 接口接收的是**数组**，`update` 接口接收的是**对象**且必须带 `id` 字段。

### 2.3 认证方式

认证通过 Cookie 完成，主要字段：

```
TMS_SESSION_ID=xxxx; rememberMe=xxxx; token=111
```

其中 `token=111` 是用户 ID，`TMS_SESSION_ID` 是会话标识。

## 3 周报 Excel 结构

周报文件为 `办公室周报2026-吴潇.xlsx`，Sheet 名为"周报"，结构如下：

| 星期 | 日期 | 工作状态 | 项目编码 | 工作内容 | 备注 |
|------|------|---------|---------|---------|------|
| 周一 | 2026-01-05 | 办公 | RD240012 | 对接需求定义 | |
| 周二 | 2026-01-06 | 办公 | RD240009 | 软著材料编写 | |
| ... | ... | 法定假 | | | 休息 |

每周之间有"本周工作重点"和"下周工作计划"分隔行，需要跳过。

工作状态分类：

- **工作日**：办公、出差、外勤 → 提交 8 小时
- **休息日**：法定假、周六、周日、年假、病假、调休等 → 跳过不提交

## 4 脚本实现

### 4.1 核心逻辑

```
读 Excel → 解析日期/状态/项目/内容 → 查询已有记录 → 调 add 或 update 接口
```

关键设计点：

1. **Cookie 持久化** — 首次输入后保存到 `cookie.txt`，自动复用，过期才提示重新输入
2. **项目编码匹配** — 读 Excel 的"项目编码"列，为空则使用默认值 `RD240009`
3. **新增 vs 更新** — 提交前先查询该日期是否已有记录，有则 update，无则 add
4. **休息日跳过** — 法定假、周末等状态直接跳过

### 4.2 提交脚本

```python
#!/usr/bin/env python3
"""工时自动填报脚本"""

import pandas as pd
import requests
import time
import os
from datetime import datetime

SCRIPT_DIR = os.path.dirname(os.path.abspath(__file__))
COOKIE_FILE = os.path.join(SCRIPT_DIR, 'cookie.txt')
EXCEL_PATH = os.path.join(SCRIPT_DIR, '办公室周报2026-吴潇.xlsx')
BASE_URL = "http://10.10.5.25:8004"
USER_ID = 111
USER_NAME = "吴潇"
DEFAULT_PROJECT_CODE = "RD240009"

WORK_STATUS = {'办公', '外勤', '出差'}
REST_STATUS = {'法定假', '周六', '周日', '年假', '病假', '调休', '事假', '婚假', '丧假', '其他'}


def api_post(cookie, url, payload):
    headers = {'Content-Type': 'application/json', 'Cookie': cookie}
    resp = requests.post(f'{BASE_URL}{url}', json=payload, headers=headers, timeout=10)
    return resp.json()


def read_excel(path):
    df = pd.read_excel(path, sheet_name='周报', header=0)
    records = []
    for _, row in df.iterrows():
        date_val = row.iloc[1]
        status = row.iloc[2]
        project_code = row.iloc[3]
        work_content = row.iloc[4]
        note = row.iloc[5]

        if pd.isna(date_val) or pd.isna(status):
            continue

        weekday = str(row.iloc[0]).strip()
        if weekday in ('下周工作计划', '本周工作重点'):
            continue

        date_str = date_val.strftime('%Y-%m-%d') if isinstance(date_val, datetime) else str(date_val)[:10]
        status = str(status).strip()

        # 项目编码为空则用默认值
        code = str(project_code).strip() if pd.notna(project_code) else DEFAULT_PROJECT_CODE

        content = str(work_content).strip() if pd.notna(work_content) else ''
        note_str = str(note).strip() if pd.notna(note) else ''

        if status in REST_STATUS:
            continue

        duration = 8
        matters = content
        if note_str and note_str not in ('休息', ''):
            matters = (matters + '\n' + note_str) if matters else note_str
        if not matters:
            matters = '工作'

        records.append({
            'date': date_str,
            'status': status,
            'duration': duration,
            'matters': matters,
            'project_code': code,
        })
    return records


def submit_add(cookie, date, duration, matters, project, task):
    task_list = project.get('projectTaskList', [])
    item = {
        'key': '000',
        'workDuration': str(duration),
        'workMatters': f'"{matters}"\n',
        'workDate': date,
        'projectId': project['id'],
        'workOvertime': '',
        'userCompellation': USER_NAME,
        'isOverTime': False,
        'taskId': task['id'],
        'taskList': task_list,
        'projectName': project['projectName'],
        'taskName': task['taskName'],
        'projectType': 1,
        'projectCode': project['projectCode'],
        'projectUsername': '',
        'projectUserName': project.get('userName', ''),
        'userId': USER_ID,
        'auditing': 0,
    }
    return api_post(cookie, '/api/dailyReport/add', [item])


def submit_update(cookie, existing, date, duration, matters, project, task):
    payload = {
        'id': existing['id'],
        'workDate': date,
        'workDuration': duration,
        'workMatters': matters,
        'workOvertime': existing.get('workOvertime', 0),
        'projectId': project['id'],
        'projectName': project['projectName'],
        'projectCode': project['projectCode'],
        'projectLeader': existing.get('projectLeader'),
        'taskId': task['id'],
        'taskName': task['taskName'],
        'userId': USER_ID,
        'userCompellation': USER_NAME,
        'createTime': existing.get('createTime'),
        'updateTime': existing.get('updateTime'),
        'auditing': existing.get('auditing', 0),
        'createBy': existing.get('createBy', USER_ID),
        'deleted': existing.get('deleted'),
        'project': {
            'id': project['id'],
            'projectName': project['projectName'],
            'projectCode': project['projectCode'],
            'projectType': project.get('projectType', 1),
            'projectStatus': project.get('projectStatus'),
            'startTime': project.get('startTime'),
            'endTime': project.get('endTime'),
            'createTime': project.get('createTime'),
            'updateTime': project.get('updateTime'),
            'remark': project.get('remark'),
            'placeOnFile': project.get('placeOnFile', 0),
            'placeOnFileTime': None,
            'salesName': None,
            'createBy': project.get('createBy'),
            'createByName': project.get('createByName'),
            'deleted': 0,
            'userId': project.get('userId'),
            'fileName': project.get('fileName', ''),
            'userName': project.get('userName'),
            'projectTaskList': None,
            'dailyReportList': None,
            'projectUser': None,
            'projectPeopleNum': None,
            'projectWorkDurationNum': None,
        },
        'projectType': 1,
        'taskList': project.get('projectTaskList', []),
        'projectUserName': project.get('userName'),
    }
    return api_post(cookie, '/api/dailyReport/update', payload)
```

## 5 踩坑记录

### 5.1 update 接口 selectOne 报错

最初尝试用 `/api/dailyReport/update` 创建新记录（不带 id），服务端返回：

```json
{"code":"202","msg":"程序异常，稍后重试","info":"Expected one result (or null) to be returned by selectOne(), but found: 12497"}
```

原因：`update` 接口的 SQL 根据条件查询记录时，没有 `id` 限定导致查到大量重复记录。解决方法是区分 add（新建）和 update（更新）两个接口。

### 5.2 add 请求体是数组而非对象

通过抓包发现 `add` 接口的请求体是 JSON 数组，每个元素代表一条日报记录。而 `update` 是单个对象。这个差异导致第一次用对象格式调 `add` 时被服务端忽略。

### 5.3 F12 Network 看不到 POST 请求

部分 Vue 项目会在页面跳转或刷新时清空 Network 记录，导致找不到请求。解决方法是用 Console 注入 XHR 拦截器，在请求发出时直接打印，不受 Network 面板影响。

### 5.4 Cookie 中的中文编码

Windows 下 Python 默认编码可能不是 UTF-8，读取包含中文的 Cookie 或 Excel 内容时需要注意编码设置。推荐在脚本中显式指定 `encoding='utf-8'`。
