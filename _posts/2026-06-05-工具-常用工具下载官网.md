## 1 官方网站

收藏的比较使用工具的官方网站，放在浏览器各种病毒啥的

### 1.1 [Everything](https://www.voidtools.com/zh-cn/)  ⭐⭐⭐⭐⭐

​	"Everything" 是 Windows 上一款搜索引擎，它能够基于文件名快速定文件和文件夹位置。不像 Windows 内置搜索，"Everything" 默认显示电脑上每个文件和文件夹 (就如其名 "Everything")。您在搜索框输入的关键词将会筛选显示的文件和文件夹。

### 1.2 [Git](https://git-scm.com/)⭐⭐⭐⭐⭐

​	Git 是一个版本控制系统。简单说：它帮你记录文件的每一次修改，随时能回到之前的任何版本。
