## 4 写文章与图片处理

### 4.1 写文章规范

文件命名：`YYYY-MM-DD-分类-标题.md`，Front Matter：

```yaml
---
layout: post
title: "文章标题"
date: 2026-05-27
category: 分类名
---
```

### 4.2 图片路径问题

Jekyll 构建时文章生成在 `/posts/标题/` 下，源文件在 `_posts/`，层级不同导致路径解析冲突：

| 写法 | Typora | Jekyll |
|------|--------|--------|
| `![x](/assets/x.png)` | ✗ | ✓ |
| `![x](../assets/x.png)` | ✓ | ✗ |
| `<img src="/assets/x.png">` | ✗ | ✓ |

结论：不存在同时满足两端的格式，靠脚本切换。

### 4.3 工作流

```
Typora 编辑 → push 前 → 网页发布
```

- 编辑阶段：图片路径 `![desc](../assets/xxx.png)`，Typora 正常预览
- 发布阶段：路径转为 `<img src="/assets/xxx.png">`
- 继续编辑：双击 `typora.bat` 转回

### 4.4 Typora 设置

偏好设置 → 图像 → 复制到指定路径，填入 `../assets`，勾选"优先使用相对路径"。粘贴截图时 Typora 自动存到 `assets/`。

### 4.5 全盘图片搜索

图片处理脚本（`python/fix_img_path.py`）支持五层搜索，找到即停：

| 层 | 范围 | 方法 | 速度 |
|----|------|------|------|
| ① | `assets/` | `isfile` | 瞬间 |
| ② | 项目目录 | `os.walk` | 快 |
| ③ | 桌面、下载、图片、文档 | `os.walk` | 几秒 |
| ④ | 全盘 | Everything `es.exe` | 秒级 |
| ⑤ | 全盘兜底 | `os.walk` | 分钟级 |

[Everything](https://www.voidtools.com/) 是 Windows 最快的文件搜索工具，`es.exe` 是其命令行接口。关键参数：

```python
subprocess.run(
    [es, '-n', '1', '-full-path-and-name', filename],
    capture_output=True, text=True, timeout=5,
)
```

- `-n 1`：只返回第一个结果
- `-full-path-and-name`：必须用这个，不能用 `-name`（后者只输出裸文件名，没有路径）
- `timeout=5`：防止 Everything 服务没响应时卡死

脚本同时做了代码块保护——围栏代码块（` ``` `）和行内代码（`` ` ``）内的图片引用不处理，防止教学示例被误改。

## 5 自动添加 Front Matter

Jekyll 文章的 front matter 和文件名里的日期 / 分类 / 标题其实是一一对应的。但手写 front matter 很容易和文件名脱节——改完文件名忘了改 `title:`，或者 `date:` 和文件名对不上，构建不会报错但页面显示就乱了。

写了个 Python 脚本，扫描 `_posts/` 下所有 `.md` 文件，根据文件名**强制重写** front matter。旧 front matter 先剥掉再重新生成，始终和文件名保持一致。

### 5.1 文件名规则

脚本依赖的文件名格式：`YYYY-MM-DD-分类-标题.md`

例如 `2026-06-02-送检-CE 检测.md` 拆出来：

| 段 | 内容 | 对应 front matter |
|----|------|-------------------|
| `2026-06-02` | 日期 | `date: 2026-06-02` |
| `送检` | 分类 | `category: 送检` |
| `CE 检测` | 标题 | `title: "CE 检测"` |

分类和标题之间用第一个 `-` 分隔，标题内部可以有空格。

### 5.2 效果

双击 `add_fm.bat`：

```
扫描 14 个文件...

  写入: 2026-06-02-送检-CE 检测.md  ->  category=送检, title=CE 检测
  跳过（文件名不匹配格式）: about.md

完成：写入 13 个，跳过 1 个
```

文件名格式不对的（比如没有日期前缀）自动跳过，不破坏内容。

### 5.3 脚本

`add_fm.bat`：

```batch
@echo off
cd /d "%~dp0"
python python\add_front_matter.py
pause
```

`python/add_front_matter.py`：

```python
#!/usr/bin/env python3
"""
根据文件名强制重写 _posts/ 下 .md 文件的 front matter。
已有 front matter 的会先剥掉再重新生成，确保和文件名一致。
"""

import os
import re
import sys

POSTS_DIR = os.path.join(
    os.path.dirname(os.path.dirname(os.path.abspath(__file__))), "_posts"
)

FILE_PATTERN = re.compile(r"^(\d{4}-\d{2}-\d{2})-(.+?)-(.+)\.md$")


def strip_front_matter(content):
    """剥掉已有的 front matter，返回纯正文"""
    if content.startswith("---"):
        end = content.find("---", 3)
        if end != -1:
            return content[end + 3:].lstrip("\n")
    return content


def process_file(filepath):
    filename = os.path.basename(filepath)
    m = FILE_PATTERN.match(filename)
    if not m:
        print(f"  跳过（文件名不匹配格式）: {filename}")
        return False

    date_str = m.group(1)
    category = m.group(2)
    title = m.group(3)

    with open(filepath, "r", encoding="utf-8") as f:
        content = f.read()

    body = strip_front_matter(content)

    front_matter = (
        f'---\n'
        f'layout: post\n'
        f'title: "{title}"\n'
        f'date: {date_str}\n'
        f'category: {category}\n'
        f'---\n\n'
    )

    with open(filepath, "w", encoding="utf-8") as f:
        f.write(front_matter + body)

    print(f"  写入: {filename}  ->  category={category}, title={title}")
    return True


def main():
    if not os.path.isdir(POSTS_DIR):
        print(f"_posts 目录不存在: {POSTS_DIR}")
        sys.exit(1)

    md_files = sorted(f for f in os.listdir(POSTS_DIR) if f.endswith(".md"))
    print(f"扫描 {len(md_files)} 个文件...\n")

    done = skip = 0
    for md in md_files:
        if process_file(os.path.join(POSTS_DIR, md)):
            done += 1
        else:
            skip += 1

    print(f"\n完成：写入 {done} 个，跳过 {skip} 个")


if __name__ == "__main__":
    main()
```

### 5.4 逻辑拆解

1. **剥旧** — `strip_front_matter()` 找到第一个 `---` 到第二个 `---` 之间的内容，整段切掉，只留正文
2. **解析文件名** — 正则 `(\d{4}-\d{2}-\d{2})-(.+?)-(.+)\.md$` 提取日期 / 分类 / 标题
3. **生成新 front matter** — 四个字段：`layout` / `title` / `date` / `category`
4. **拼回去** — 新 front matter + 原正文，覆盖写入

整个过程是**幂等的**——重复跑不会叠多层 front matter，因为每次都是先剥再写。

## 6 标题自动编号

写文章时手写章节编号很麻烦：调整结构之后编号全乱，还得一个个改。写了个 Python 脚本，自动扫描 `_posts/` 下的 Markdown 文件，对 `##` 以下的标题按层级编号。重复跑幂等——旧编号先剥掉再重写。

### 6.1 效果

输入：

```markdown
## 简介

### 背景

### 目的

## 一、中文序号章节

### 1.1 已有旧编号的子节
```

运行后：

```markdown
## 1 简介

### 1.1 背景

### 1.2 目的

## 2 中文序号章节

### 2.1 已有旧编号的子节
```

规则：
- `##` → `1`、`2`、`3`……（h2 级，不加尾点）
- `###` → `1.1`、`1.2`、`2.1`……（h3 级）
- `####` → `1.1.1`、`1.1.2`……（h4 级，依此类推）
- 自动剥除旧编号：数字编号（`1.`、`1.1`、`2.3.1`）和中文序号（`一、`、`二、`）都支持
- `#`（h1）不参与编号
- Front matter 和代码块内容跳过

### 6.2 脚本

`auto_number.bat`：

```batch
@echo off
cd /d "%~dp0"

python -c "print('ok')" >nul 2>&1
if %errorlevel% neq 0 (
    echo 未找到 Python，请先安装 Python
    pause
    exit /b 1
)

python python\auto_number_headings.py _posts\
pause
```

`python/auto_number_headings.py`：

```python
"""
Markdown 标题自动编号

从 h2（##）开始往下累加：
  ## → 1 / 2 / 3
  ### → 1.1 / 1.2 / 2.1
  #### → 1.1.1 / 1.1.2
  以此类推（编号后不加点）

自动去除已有编号再重新编排。跳过 front matter 和围栏代码块。
支持去除：纯数字编号（"1."、"1.1"、"2.3.1"）和中文序号（"一、"、"二、"等）。
"""

import os
import re
import sys

BLOG_ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))

HEADING_RE = re.compile(r'^(#{2,6})\s+(.*)$')

# 匹配已有的数字编号前缀（如 "1."、"1.1"、"2.3.1"）
EXISTING_NUM_RE = re.compile(r'^(\d+(?:\.\d+)*)\.?\s+(.+)$')

# 匹配中文序号前缀（如 "一、"、"二、"、"十、"等）
CHINESE_NUM_RE = re.compile(r'^[一二三四五六七八九十百]+[、．.]\s*(.+)$')

FENCE_RE = re.compile(r'^```', re.MULTILINE)


def strip_number(text):
    """循环除去标题已有的编号前缀，直到不匹配为止"""
    while True:
        changed = False
        m = EXISTING_NUM_RE.match(text)
        if m:
            text = m.group(2).strip()
            changed = True
            continue
        m = CHINESE_NUM_RE.match(text)
        if m:
            text = m.group(1).strip()
            changed = True
            continue
        if not changed:
            break
    return text


def number_headings(content):
    """对正文中的 h2+ 标题自动编号"""
    lines = content.split('\n')
    result = []
    in_front_matter = False
    fm_dashes = 0
    in_code = False

    counters = [0, 0, 0, 0, 0]  # 索引 0 = h2, 1 = h3, ...

    for line in lines:
        # 处理 front matter
        if not in_code:
            if line.strip() == '---':
                fm_dashes += 1
                if fm_dashes == 1:
                    in_front_matter = True
                    result.append(line)
                    continue
                elif fm_dashes == 2:
                    in_front_matter = False
                    result.append(line)
                    continue

        if in_front_matter:
            result.append(line)
            continue

        # 处理代码块
        if FENCE_RE.match(line):
            in_code = not in_code
            result.append(line)
            continue

        if in_code:
            result.append(line)
            continue

        # 匹配标题
        m = HEADING_RE.match(line)
        if m:
            hashes = m.group(1)
            text = m.group(2)
            level = len(hashes) - 2  # h2 → 0, h3 → 1, ...

            pure_text = strip_number(text)

            counters[level] += 1
            for i in range(level + 1, len(counters)):
                counters[i] = 0

            number = '.'.join(str(c) for c in counters[:level + 1])
            result.append(f'{hashes} {number} {pure_text}')
        else:
            result.append(line)

    return '\n'.join(result)


def main():
    if len(sys.argv) < 2:
        print('用法: python auto_number_headings.py <markdown文件或目录>')
        sys.exit(1)

    target = sys.argv[1]
    if not os.path.isabs(target):
        target = os.path.join(BLOG_ROOT, target)

    if os.path.isfile(target):
        files = [target]
    elif os.path.isdir(target):
        files = sorted(
            os.path.join(target, f)
            for f in os.listdir(target)
            if f.endswith('.md')
        )
    else:
        print(f'找不到: {target}')
        sys.exit(1)

    for md_path in files:
        with open(md_path, 'r', encoding='utf-8') as f:
            original = f.read()

        modified = number_headings(original)

        if modified == original:
            print(f'无需修改: {os.path.basename(md_path)}')
            continue

        with open(md_path, 'w', encoding='utf-8') as f:
            f.write(modified)

        print(f'已编号:   {os.path.basename(md_path)}')


if __name__ == '__main__':
    main()
```

### 6.3 编号逻辑

维护一个 5 位计数器数组 `counters`，索引 0 对应 `##`，索引 1 对应 `###`，以此类推。遇到标题时：

1. 当前层级计数器 +1
2. 所有更深层级计数器清零
3. 把 `counters[0]` 到 `counters[level]` 用 `.` 连接，得到编号

例如：

```
## 标题  →  counters = [1,0,0,0,0]  →  "1"
## 标题  →  counters = [2,0,0,0,0]  →  "2"
### 子节 →  counters = [2,1,0,0,0]  →  "2.1"
### 子节 →  counters = [2,2,0,0,0]  →  "2.2"
## 标题  →  counters = [3,0,0,0,0]  →  "3"
```

### 6.4 剥旧编号

`strip_number` 用两个正则**循环**匹配，剥到干净为止：

```python
# 数字编号：必须数字后跟空格+内容，避免误匹配纯数字标题
EXISTING_NUM_RE = re.compile(r'^(\d+(?:\.\d+)*)\.?\s+(.+)$')

# 中文序号：一、二、三……
CHINESE_NUM_RE = re.compile(r'^[一二三四五六七八九十百]+[、．.]\s*(.+)$')
```

数字编号要求后面有空格和内容，所以 `## 42` 这种纯数字标题不会被误识别。

**为什么要循环**：标题可能出现多层编号叠加的情况。比如先手写了中文序号 `一、开发环境准备`，脚本跑完变成 `## 1 一、开发环境准备`——上次的编号没剥干净。单次匹配只会剥掉 `1` 而留下 `一、`，导致中文序号永远残留。循环剥除可以处理任意层级叠加的脏编号。

## 8 搜索功能与暗号解锁

首页顶部搜索框，纯前端 JS，零第三方库。**搜索框同时兼任隐藏文章的暗号解锁开关**——在 `_config.yml` 的 `secret_categories` 中列出的分类，以及文章 front matter 中标记 `secret: true` 的文章，默认不在首页和侧边栏显示。只有在搜索框输入正确暗号（默认 `open-ocamar`）才会解锁。

| 功能 | 说明 |
|------|------|
| 实时过滤 | `input` 事件触发 |
| 匹配范围 | 文章标题 + 分类名称 |
| 空分类隐藏 | 某分类下全部过滤掉则卡片消失 |
| 暗号解锁 | 搜索框输入暗号切换 `body.secret-unlocked` 类 |
| 持久化 | 解锁状态存 `localStorage`，刷新保持 |
| 中文支持 | `indexOf` 直接匹配 |

暗号通过 djb2 哈希校验，不存明文。解锁后 `body` 加 `secret-unlocked` 类，CSS 规则 `.secret-post { display: none; }` + `body.secret-unlocked .secret-post { display: list-item; }` 控制显隐。再次输入同一暗号即重新锁定。

每个 `<li>` 挂 `data-title` 和 `data-category`，搜索时直接读 DOM：

```javascript
(function() {
  var input = document.getElementById('search');
  var cards = document.querySelectorAll('.cat-card');
  var items = document.querySelectorAll('.cat-articles li');

  function filter() {
    var q = input.value.trim().toLowerCase();

    items.forEach(function(item) {
      var title = (item.getAttribute('data-title') || '').toLowerCase();
      var cat   = (item.getAttribute('data-category') || '').toLowerCase();
      if (!q || title.indexOf(q) >= 0 || cat.indexOf(q) >= 0) {
        item.classList.remove('hidden');
      } else {
        item.classList.add('hidden');
      }
    });

    cards.forEach(function(card) {
      var visible = card.querySelectorAll('.cat-articles li:not(.hidden)');
      card.classList.toggle('hidden', visible.length === 0);
    });
  }

  input.addEventListener('input', filter);
})();
```

两步走：先过滤单篇文章，再隐藏空卡片。`indexOf` 比正则简单，十几篇文章完全够用，无需 Algolia/Lunr。

## 9 侧边目录导航

右侧悬浮 TOC，自动扫描 h2/h3 生成目录，点击平滑跳转，滚动高亮当前章节：

| 功能 | 说明 |
|------|------|

| 平滑跳转 | 点击滚到对应标题，留 70px 间距 |
| 滚动高亮 | 从后往前找第一个 `top <= 80` 的标题高亮 |
| 层级缩进 | h3 比 h2 缩进 12px |
| 窄屏隐藏 | 宽度 ≤ 1380px 时自动消失 |

如果标题没有 `id`，JS 自动补 `heading-0`、`heading-1` 等。TOC 定位通过 `position: fixed` + `calc` 计算实现。

## 10 Liquid 标签逃逸

写 Jekyll 教程时，代码块里展示的 Liquid 模板代码（`{% raw %}{{ }}{% endraw %}`、`{% raw %}{% %}{% endraw %}`）会被 Jekyll 当成真实指令执行，导致构建失败。

### 10.1 典型场景

① 展示首页循环模板：

{% raw %}
```liquid
{% for post in site.posts %}
<li>
  <a href="{{ post.url }}">{{ post.title }}</a>
</li>
{% endfor %}
```
{% endraw %}

其中的 `{% raw %}{{ post.url }}{% endraw %}` 被真实渲染。

② 展示 `post.html` 布局：

{% raw %}
```html
<div class="post-content">
  {{ content }}
</div>
```
{% endraw %}

`{% raw %}{{ content }}{% endraw %}` 递归渲染当前文章自身——把自己嵌进自己，死循环导致构建超时。

### 10.2 修复

用 raw 标签包裹：

{% raw %}
```liquid
{% raw %}
```html
{% for post in site.posts %}
<li>
  <a href="{{ post.url }}">{{ post.title }}</a>
</li>
{% endfor %}
```
{% endraw %}
```
{% endraw %}

一句话：**文章里出现 Liquid 模板标签就用 raw 包起来。**

### 10.3 raw 不能嵌套

Liquid 的 raw 不支持嵌套——第一个 raw 闭合标签就结束全部 raw 层。如果文章自身要展示 raw 标签（比如本文），需要分段处理：把 raw 标签拆成两半，用多个 raw 块 + 变量输出拼接。

## 11 GitHub Pages Fork 部署

把别人的 GitHub Pages 仓库复制成自己的站点，不涉及 Fork 提 PR。

```bash
# 五行命令
git clone https://github.com/原作者/原作者.github.io.git
cd 原作者.github.io
git remote remove origin
git remote add origin https://github.com/你的用户名/你的用户名.github.io.git
git push -u origin main
```

剩下三步：
1. GitHub 建同名仓库 `你的用户名.github.io`（不要加 README）
2. Settings → Pages → 选 main 分支，Save
3. 改 `_config.yml` 里的 title、description、url

注意检查原仓库的 LICENSE、`CNAME`、Google Analytics 等配置，需要的保留，不需要的删掉。

| **Jekyll** | 静态站点生成器，GitHub Pages 原生支持 |

### 12.2 自动化脚本

| 脚本 | 用途 |
|------|------|
| `typora.bat` | 图片转为 Typora 预览格式（`../assets/` 相对路径） |
| `web.bat` | 图片转为网页格式（`/assets/` 绝对路径） |
| `add_fm.bat` | 根据文件名自动生成 Front Matter |
| `auto_number.bat` | 标题按层级自动编号 |
| `compress.bat` | 图片压缩（webp / 质量调整） |
| `autocommit.bat` | git add → commit → push（一键三连） |
| `git_push.bat` | git push 到 GitHub |
| `git_reset.bat` | git reset 撤销未推送的提交 |
| `git_rollback.bat` | git 回滚到指定历史版本 |

### 12.3 完整发布流程

```
Typora 写文章
  ↓
typora.bat        （图片路径确保预览正常）
  ↓
web.bat           （图片路径转网页格式）
  ↓
add_fm.bat        （根据文件名补齐 Front Matter）
  ↓
auto_number.bat   （标题自动编号）
  ↓
autocommit.bat    （git add + commit + push）
  ↓
GitHub Pages 1–2 分钟自动部署
```
