## 1 概述

本手册面向研发测试人员，介绍星链类别设备的基础测试方法，涵盖**配网**、**OTA 升级**以及**蓝牙模块参数设置**三大环节，用于验证设备联网、固件更新与蓝牙定位功能是否正常。详细测试项与验收标准不在本手册范围内。

### 1.1 设备说明

星链类别设备是一类集成多无线模块的网关设备，主要包含以下无线单元：

| 模块 | 芯片 / 实现 | 接口 | 职责 |
|------|------|------|------|
| WiFi /LAN | RTL8720DN（BW16）/华为网关/新华三网关/LAN 网口 | UART | 与引擎进行数据传输      |
| 蓝牙定位模块 | EFR32BG22/ch592 | SPI | iBeacon 扫描 / 蓝牙定位 |
| Sub-GHz 射频 | — | SPI | 终端通信 |

### 1.2 星链转发程序

星链转发程序（Engline.Sharlink.Center）用于在设备与服务器之间中转数据，OTA 升级也依赖该程序转发固件。不同设备形态对转发程序的依赖不同：

| 设备形态 | 转发程序 |
|----------|----------|
| LAN 星链网关 | 不需要（数据直推服务器） |
| 其他星链网关 | 需要 |

> **提示：** 转发程序的下载与启动见 ## 2 环境准备，OTA 升级流程见 ## 4。

## 3 配置网络

设备首次使用或更换网络环境时需要配置网络。星链类别设备的配网方式取决于设备类型，分为三类：

| 配网方式 | 适用设备 | 说明 |
|----------|----------|------|
| 蓝牙配网（InfusionLE） | 蓝牙网关、面板型蓝牙星链网关 | 通过 BLE 广播配网，用 InfusionLE 软件写入 WiFi 凭证 |
| 直接访问基站 IP / Console | LAN星链网关                  | 直接访问基站的 IP 地址或 Console 口配置网络 |
| 华为/新华三/海康 | PCIE星链网关，USB 星链网关 | 参考官方配置 |

> **提示：** 配网前先确认设备类型对应的配网方式，选错方式无法完成配网。

### 3.1 蓝牙配网（蓝牙网关 / 面板型蓝牙星链网关）

蓝牙网关与面板型蓝牙星链网关通过 BLE 广播配网，使用 InfusionLE 软件写入 WiFi 凭证。

> **关于蓝牙名称：** 设备配网模式下 BLE 会广播名称 `ocamar_XXXXXXXX`，其中 `XXXXXXXX` 为设备 Part No 的十六进制表示（例如 Part No 为 `91 60 00 02` 时广播名为 `ocamar_91600002`）。扫描时按此名称识别目标设备。

#### 3.1.1 下载并打开配置软件

下载 InfusionLE.zip 并解压，打开软件主程序。

<img src="/assets/image-20260727101542528.png" alt="image-20260727101542528">

<img src="/assets/image-20260727101810901.png" alt="image-20260727101810901">

#### 3.1.2 进入配网模式

点击软件中的「配置网络」按钮，进入配网界面。

<img src="/assets/image-20260727101931340.png" alt="image-20260727101931340">

#### 3.1.3 扫描并连接设备

**步骤一：扫描设备**

点击「扫描设备」，软件开始扫描附近的 BLE 广播，根据设备名称 `ocamar_XXXXXXXX` 找到目标设备。

<img src="/assets/image-20260727111354000.png" alt="image-20260727111354000">

**步骤二：选择设备**

在扫描结果中选择需要配置的设备。

<img src="/assets/image-20260727111230557.png" alt="image-20260727111230557">

**步骤三：连接设备**

点击「连接」即可与设备建立 BLE 连接。

<img src="/assets/image-20260727111558040.png" alt="image-20260727111558040">

> <span style="color: red;">**注意：设备配网模式有超时机制（默认 10 分钟），超时或配网完成后 BLE 会自动关闭，且不会再次打开。若扫描不到设备，请对设备重新上电以重新进入配网模式。**</span>

#### 3.1.4 读取与保存配置

连接成功后，首先点击「读取配置」获取设备当前参数，然后依次保存各项配置。首先保存 WiFi 配置。

<img src="/assets/image-20260727111813314.png" alt="image-20260727111813314">

#### 3.1.5 设置本地网络（固定 IP）

建议将设备本地 IP 设置为固定 IP，避免 DHCP 分配变动导致推送链路中断。

**步骤一：查看空闲 IP**

使用软件查看当前网段中未占用的 IP 地址，其中红色标记表示未被占用。

<img src="/assets/image-20260727132056829.png" alt="image-20260727132056829">

**步骤二：设置设备 IP**

将设备 IP 设置为选定的空闲地址，例如 `10.10.1.194`。

<img src="/assets/image-20260727132439488.png" alt="image-20260727132439488">

#### 3.1.6 设置推送服务

将推送服务地址改为测试服务器的 IP（测试环境通常为本机 IP，以实际为准）。

<img src="/assets/image-20260727112046052.png" alt="image-20260727112046052">

<img src="/assets/image-20260727111908479.png" alt="image-20260727111908479">

#### 3.1.7 开启联网模式

最后点击「开启联网模式」。**这一步是关键**——只有执行此操作，之前的所有配置才会真正写入设备并生效。

<img src="/assets/image-20260727112158352.png" alt="image-20260727112158352">

开启后设备会关闭 BLE 配网、连接 WiFi 并建立与服务器的 TCP 链路。可在转发服务器侧确认设备是否成功上线。

### 3.2 直接访问基站 IP / Console 配网（LAN 星链网关）

LAN 星链网关不使用蓝牙配网，而是**直接访问基站的 IP 地址或 Console 口**完成网络配置。

| 配置途径 | 说明 |
|----------|------|
| 访问基站 IP | 通过浏览器或工具登录基站管理地址，在 Web 界面配置网络参数 |
| Console 口 | 通过串口连接基站 Console 口，以命令行方式配置网络参数 |

> **说明：** 此方式的具体操作步骤不在本手册范围内，请参考对应设备型号的配置文档。

### 3.3 华为 / 新华三 / 海康网关配网（PCIE 星链网关 / USB 星链网关）

PCIE 星链网关与 USB 星链网关通过华为、新华三或海康网关接入网络，配网与转发配置参考对应网关的官方文档。

> **说明：** 此方式的具体操作步骤不在本手册范围内，请参考对应网关的官方配置文档。

## 4 OTA 升级

OTA 升级用于更新设备固件，需通过「星链转发服务器」中转数据，再用「OTA 升级助手」下发固件。

### 4.1 启动星链转发服务器

下载并解压 Engline.Sharlink.Center，双击打开软件并开始监听。

<img src="/assets/image-20260727113238644.png" alt="image-20260727113238644">

等待星链设备连接成功（连接速度与实际网络状况有关）。

<img src="/assets/image-20260727113500647.png" alt="image-20260727113500647">

### 4.2 启动 OTA 升级助手

下载 OTA 升级助手并打开。设备配网联网完成后，先点击「连接 OTA 服务器」。

<img src="/assets/image-20260727114015434.png" alt="image-20260727114015434">

### 4.3 选择固件并升级

选择待升级的固件文件，点击「升级」开始下发。

<img src="/assets/image-20260727114113167.png" alt="image-20260727114113167">

> **说明：** 若升级后提示「基站版本异常」，请再点击一次「升级」。此时即使显示版本号相同，也认定为升级成功。

<img src="/assets/image-20260727114254102.png" alt="image-20260727114254102">

### 4.4 固件命名规则

固件文件名通过后缀区分角色，不同角色对应不同芯片，升级时需选择正确文件：

| 角色 | 固件命名格式 | 示例 |
|------|--------------|------|
| 控制主机（AT32） | `nameVx.x.x.E0.bin` | `nameV1.0.1.E0.bin` |
| FG14 主机 | `nameVx.x.x.E1.bin` | `nameV1.0.1.E1.bin` |
| FG14 从机 | `nameVx.x.x.E2.bin` | `nameV1.0.1.E2.bin` |
| 蓝牙主机 | `nameVx.x.x.E3.bin` | `nameV1.0.1.E3.bin` |
| 蓝牙从机 | `nameVx.x.x.E4.bin` | `nameV1.0.1.E4.bin` |

> **提示：** 面板型蓝牙星链网关（86 盒）只有「控制主机（AT32）」和「蓝牙主机」两个角色，升级时仅需 E0 和 E3 文件。

## 6 常见问题

### 6.1 扫描不到设备蓝牙（蓝牙网关 / 面板型蓝牙星链网关）

**现象：** 配网时 InfusionLE 扫描不到 `ocamar_XXXXXXXX` 设备。

**处理：**

1. 确认设备已重新上电——设备配网模式配网完成后 BLE 自动关闭，**仅断电重启**才能重新进入配网模式
2. 确认设备未处于已联网状态：一旦配网完成或超时，BLE 即被关闭，不会再打开
3. 确认测试电脑蓝牙正常，且与设备距离在有效范围内

### 6.2 WiFi 连接失败（蓝牙网关 / 面板型蓝牙星链网关）

**现象：** 配网完成后设备 WiFi 连接失败，日志出现 EAP 认证错误（如 `+WJEAP:66`）。

**处理：**

1. 核对配网时填写的 WiFi 认证方式（PEAP / TLS / TTLS）与 AP 实际配置是否一致
2. 检查 EAP 用户名格式，部分企业 WiFi 要求 `domain\username` 格式
3. 确认密码与证书配置正确
4. 若需重新配网，需对设备断电重启后重新进入配网模式

### 6.3 设备已联网但无法推送数据

**现象：** 设备 WiFi 连接正常，但服务器收不到推送数据，日志出现 `HeartBeat ack timeout`。

**处理：**

1. 确认推送服务地址与端口配置正确，且服务器已启动监听
2. 检查防火墙是否放行相应端口
3. 确认设备本地 IP 与服务器在同一网段且可达
4. 心跳超时后设备会自动重连 socket，若长时间未恢复，检查服务器侧连接状态

### 6.4 OTA 升级提示版本异常

**现象：** 升级后提示「基站版本异常」。

**处理：**

1. 再点击一次「升级」，版本号相同也认定为升级成功
2. 确认选择的固件文件与设备角色匹配（见 4.4 固件命名规则）
3. 确认星链转发服务器已启动监听，且设备已成功连接
