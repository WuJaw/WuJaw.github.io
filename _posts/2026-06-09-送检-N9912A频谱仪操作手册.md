### 1.7 效果总结

> 此模式下迹线为 **Normal（实时）**，Peak Search 抓取的是**当前时刻波形的最高点**，信号一旦消失峰值立刻就没了，适合用来测量持续发射的 CW 信号或稳定信号源。

## 2 抓调制波【瞬时】最高值（峰值保持）

> 含义：把**历史上出现过的所有最高点冻在屏幕上**，信号早走了也能看到。适合抓脉冲、突发、瞬态信号。

**前面的步骤与抓载波相同**，从本节开始不同 ↓

## 3 两版本对比速查表

| 对比项            | 版本 A（实时）       | 版本 B（瞬时）                      |
| ----------------- | -------------------- | ----------------------------------- |
| Trace State       | Normal               | Max Hold                            |
| 峰值时效性        | 只有当前这一刻       | 历史所有时刻的最高                  |
| 信号消失后峰值    | ❌ 立刻消失           | ✅ 冻在屏幕上                        |
| Marker 锁哪条轨迹 | Trace 1（实时）      | **Trace 2（Max Hold）**             |
| 适合测什么        | 持续信号、CW         | 脉冲、突发、瞬态                    |
| 核心按键          | Marker → Peak Search | Trace→Max Hold → Marker→Peak Search |
