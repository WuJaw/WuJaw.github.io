# 2026-05-28 工作日志

## 修复图片不显示问题

- 文章：`_posts/2025-05-27-A1 系列蜂巢基站.md`
- 原因：图片路径为 Windows 绝对路径（`C:\Users\...`），Jekyll 无法识别
- 修复：图片放 `assets/`，发布用 `<img src="/assets/xxx.png">`，编辑用 `![x](../assets/x.png)`
- 约定：图片统一放 `assets/`（非 `_posts/assets/`），通过脚本切换格式

## 图片路径双脚本方案

- `change/fix_img_path.py`：转网页格式 `<img src="/assets/xxx.png">`，自动拷贝图片
- `change/fix_img_reverse.py`：转 Typora 格式 `![x](../assets/x.png)`
- `change/typora.bat` / `web.bat`：双击运行的快捷入口
- 工作流：Typora 编辑 → web.bat → push，继续编辑 → typora.bat
