## 1. 打开串口检测工具

首先点击串口检测工具。

![串口检测工具入口](/assets/操作步骤/img/image1.png)

---

## 2. 连接设备

插入串口工具，就会弹出实时的串口。

![弹出实时串口](/assets/操作步骤/img/image2.png)

---

## 3. 打开调试软件

打开另外一个软件（串口调试助手）。

![串口调试软件](/assets/操作步骤/img/image3.png)

---

## 4. 配置串口参数

然后进入如下配置：

![串口参数配置界面](/assets/操作步骤/img/image4.png)

**参数说明：**

| 参数 | 设置值 |
|------|--------|
| 波特率 | **1000000** |
| 串口号 | 刚才弹出的端口号（例如 COM34） |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | None |

> **提示**：串口号如果没看清楚，可以反复拔插设备即可重新触发弹窗确认。

点击 **打开设备**，有弹窗点击 **确定** 即可。

---

## 5. 发送命令切换射频模式

在输入框中输入命令字符，点击 **发送**。

初始状态下发送 `1` 即进入 2402 MHz 调制波模式，发送下表中的命令可切换不同的射频模式：

![发送命令界面](/assets/操作步骤/img/image5.png)

### 命令映射表

| 发送 | 串口回显 | 含义 |
|------|----------|------|
| `1` | `1:Rail mode is 2402MHz-modulated` | 2402 MHz 调制波 |
| `2` | `2:Rail mode is 2402MHz-carrier`   | 2402 MHz 载波   |
| `3` | `3:Rail mode is 2480MHz-modulated` | 2480 MHz 调制波 |
| `4` | `4:Rail mode is 2480MHz-carrier`   | 2480 MHz 载波   |
| `5` | `5:Rail mode is 2481MHz-modulated` | 2481 MHz 调制波 |
| `6` | `6:Rail mode is 2481MHz-carrier`   | 2481 MHz 载波   |
| `7` | `7:Rail mode is 2442MHz-modulated` | 2442 MHz 调制波 |
| `8` | `8:Rail mode is 2442MHz-carrier`   | 2442 MHz 载波   |
| `9` | `9:Rail mode is 2440MHz-modulated` | 2440 MHz 调制波 |
| `a` / `A` | `a:Rail mode is 2440MHz-carrier` | 2440 MHz 载波   |

> **注意**：发送下一条命令时，固件会自动停止当前模式并切换到新模式，无需手动重置设备。

![命令切换示意](/assets/操作步骤/img/image6.png)

## 6. 设备接法

设备接法如下图所示：

![设备接线示意图](/assets/操作步骤/img/image7.jpeg)

| 引脚 | 说明 |
|------|------|
| TX   | 连接上位机 RX |
| RX   | 连接上位机 TX |
| GND  | 共地 |
| VCC  | 供电（3.3 V） |
