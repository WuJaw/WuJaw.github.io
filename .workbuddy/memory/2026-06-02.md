# 2026-06-02

## 功能开关配置系统
在 `_config.yml` 新增 `features` 配置段，支持 4 个模块的独立显隐控制：search（搜索框）、site_nav（左侧站点目录）、toc（右侧文章大纲）、copy_button（代码块复制按钮）。各模板通过 `{% if site.features.xxx %}` Liquid 条件判断实现构建时控制，设为 false 即完全不输出对应 HTML/JS。

## 隐藏分类功能
在 `_config.yml` 新增 `hidden_categories` 列表，首页和左侧目录均通过 `{% unless site.hidden_categories contains cat_name %}` 过滤，构建时不渲染被隐藏分类的卡片和目录项。当前已隐藏「博客搭建」分类。

## 工具页面集成
将两个独立 HTML 工具（EFR32 容量剩余计算器、CRC16 校验工具）放入 `tools/` 静态目录，新建 `_posts/2026-06-02-工具000-在线工具.md` 归入「工具」分类，使用卡片式布局 + 按钮链接跳转。CSS 中新增 `.tool-list` / `.tool-item` / `.btn` 样式。
