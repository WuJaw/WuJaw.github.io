## 修复 git_rollback.bat 乱码

`git_rollback.bat` 由于保存为 UTF-8 编码，在 Windows cmd（GBK）下运行时中文全部乱码。
用 Python 将文件从 UTF-8 重新编码为 GBK 后，乱码问题解决。
同时确认项目中其他所有 .bat 文件（git_reset、typora、web、git_push、autocommit、add_fm、auto_number）均为 GBK 编码，无问题。

> 规律：以后新建 .bat 文件中文会乱码，最稳妥的方案是**完全用纯英文/ASCII**，彻底规避编码问题。不要试图用 chcp 65001 解决，因为字体渲染仍可能失败。
