## 1 调试软件安装

### 1.1 下载X shell 免费版本

+ X shell免费版本下载：[家庭/学校免费 - NetSarang Website (xshell.com)](https://www.xshell.com/zh/free-for-home-school/)

<img src="/assets/csdn_32514d39.png" alt="">

该软件主要是用来做串口调试助手的，当然你有其他的也可以尝试其他的。

### 1.2 安装X shell

+ 打开文件

<img src="/assets/csdn_61455c33.png" alt="">

+ 点击下一步

<img src="/assets/csdn_d9155423.png" alt="">

+ 勾选协议，点击下一步

<img src="/assets/csdn_d6e7b1d2.png" alt="">

+ 可以修改安装位置，我们这里选择默认直接下一步.

<img src="/assets/csdn_f9169f27.png" alt="">

+ 点击软件安装

<img src="/assets/csdn_42b85ceb.png" alt="">

+ 完成安装，点击完成

<img src="/assets/csdn_111ee045.png" alt="">

+ 如果提醒需要注册我们可以选择注册一下.

<img src="/assets/csdn_ff9a3626.png" alt="">

+ 点击后来进入界面，选择新建会话

<img src="/assets/csdn_f7d8a76a.png" alt="">

+ 首先协议选择串口协议 

<img src="/assets/csdn_66f0ba5d.png" alt="">

+ 再点击串口

<img src="/assets/csdn_b984d222.png" alt="">

+ 这些串口的参数，相信大家都很熟悉了，我们直接按照自己的实际的串口进行选择即可。

<img src="/assets/csdn_7d6bf6be.png" alt="">

+ 最后点击确定。

<img src="/assets/csdn_beceb788.png" alt="">

+ 点击连接

<img src="/assets/csdn_839e1891.png" alt="">

+ 连接上 X shell。

<img src="/assets/image-20260616151159107.png" alt="image-20260616151159107">

+ 点击黑框，输入快捷键 ctrl+ q 就可以开始获取到数据了

<img src="/assets/image-20260616151334947.png" alt="image-20260616151334947">
