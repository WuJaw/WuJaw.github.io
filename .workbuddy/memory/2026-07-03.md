## 隐藏文章功能（暗号解锁）

在首页搜索框中实现了隐藏文章的暗号解锁机制：
- 文章 front matter 加 `secret: true` 即标记为隐藏
- 在搜索框输入暗号（默认 `open-sesame`）即可切换显示/隐藏
- 解锁状态存 localStorage，刷新后保持
- 首页分类卡片计数自动排除未解锁的隐藏文章
- 侧边栏目录也同步隐藏/显示

修改文件：
- `index.html`：secret-post 类标记 + djb2 hash 暗号检测 + 计数修正
- `_layouts/default.html`：侧边栏 secret-post CSS + localStorage 检查脚本

修改暗号方法：浏览器控制台执行 `djb2('新暗号')`，把返回值填入 index.html 的 `SECRET_HASH`。
