# 2026-06-05

## 修复 auto_number_headings.py

- **编号格式**：从 `{number}. {text}` 改为 `{number} {text}`（去掉末尾的点）
- **strip_number 增强**：
  - 数字编号正则改为 `r'^(\d+(?:\.\d+)*)\.?\s+(.+)$'`，要求数字后必须有空格+内容，避免误匹配纯数字标题
  - 新增中文序号识别：`r'^[一二三四五六七八九十百]+[、．.]\s*(.+)$'`，支持 "一、"、"二、" 等格式剥除
- **循环剥除**：strip_number 改为 while 循环，解决 "1 一、标题" 这种多层叠加编号残留问题
- 效果：`## 1 章节`，`### 1.1 子章节`，支持重跑幂等
