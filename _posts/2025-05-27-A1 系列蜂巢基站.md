# A1 系列蜂巢基站开发部署手册

> 本文档记录 A1 系列蜂巢基站的远程开发、编译、部署及日志排查流程。

---

## 一、开发环境准备

### 1.1 安装 VS Code

- 下载安装 [Visual Studio Code](https://code.visualstudio.com/)

### 1.2 安装 Remote SSH 插件

在 VS Code 扩展市场中搜索并安装 **Remote - SSH** 插件。

---

## 二、连接基站

1. 打开 VS Code，按 `F1` 或 `Ctrl+Shift+P` 打开命令面板
2. 输入 `Remote-SSH: Connect to Host`
3. 输入基站 IP 地址，连接成功后打开远程目录

---

## 三、编译流程

进入项目目录后，执行以下命令：

```bash
# 清理上次编译产物
make clean

# 重新编译
make
```

编译完成后，生成的可执行文件为 `./iot_app`。

---

## 四、部署流程

### 4.1 停止服务

```bash
systemctl stop iot_app.service
```

### 4.2 替换可执行文件

```bash
cp ./iot_app /usr/local/bin/iot_service/
```

### 4.3 启动服务

```bash
systemctl start iot_app.service
```

### 4.4 查看服务状态

```bash
systemctl status iot_app.service
```

---

## 五、访问与配置

### 5.1 Web 管理界面

基站管理页面地址（示例）：

```
http://10.10.5.213:8090
```

### 5.2 日志路径

日志服务程序位于：

```bash
cd /usr/local/bin/iot_service/log/debug
```

---

## 六、日志查看

### 6.1 实时查看日志

```bash
tail -f ./debug.log
```

### 6.2 日志过滤

按关键词过滤日志内容，例如过滤特定设备数据：

```bash
tail -f ./debug.log | grep "91 e0 03 16"
```

---

## 七、文件打包与下载

### 7.1 安装 zip 工具

```bash
apt install zip
```

### 7.2 压缩目录

```bash
zip -r ./2.iot_service20260506.zip ./2.iot_service/
```

### 7.3 下载到本地

在 VS Code 文件浏览器中，右键点击目标文件，选择 **下载** 即可将文件保存到本地。

---

## 八、Git 操作

### 8.1 克隆仓库

```bash
git clone git@10.10.5.66:root/iot_integrated_gateway.git
```

### 8.2 Git 全局配置

**禁用行尾符自动转换**（防止 Windows/Linux 换行符冲突）：

```bash
git config --global core.autocrlf false
```

**允许处理长路径**（Windows 下克隆深目录仓库时需要）：

```bash
git config --global core.longpaths true
```
