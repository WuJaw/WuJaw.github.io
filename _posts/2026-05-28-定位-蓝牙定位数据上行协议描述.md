## 1 整体链路

```c
1蓝牙标签广播──▶ 2定位器──▶ 3基站──▶ 4引擎──▶ 5第三方
```
------

### 1.1 蓝牙标签广播

标签以 BLE Advertising 形式周期性发射，单包结构参考，《昂科蓝牙设备 标准信道广播包通信协议v1.0》3.1.27 标签BLE通用数据(L2B)

上报字段 2.2.1 adv-Structuer2

| 字段     | 说明              | 长度    | 备注              |
| -------- | ----------------- | ------- | ----------------- |
| 厂商信息 | Manufacturer      | 2 bytes | 昂科固定0x00 0xff |
| 携带数据 | Manufacturer Data | 12bytes | 最后一位为seq     |



### 1.2 定位器

对收到的符合《昂科蓝牙设备 标准信道广播包通信协议v1.0》广播数据进行解析，并打包《下方字段就是Adv list的实际内容

| 字段     | 说明                       | 长度    | 备注              |
| -------- | -------------------------- | ------- | ----------------- |
| 厂商信息 | Manufacturer               | 2 bytes | 昂科固定0x00 0xff |
| 携带数据 | Manufacturer Data          | 12bytes | 最后一位为seq     |
| RSSI     | 定位器收到该蓝牙的信号强度 | 1byte   | 有符号 -128到127  |

### 1.3 基站

将打包数据内容进行转发  定位平台通讯协议V2.11.24.docx》3.2.24 标签BLE通用数据(B2D)

### 1.4 引擎

将包内数据进行提取并发送给第三方

| 字段          | 说明                             | 长度    | 备注              |
| ------------- | -------------------------------- | ------- | ----------------- |
| 定位器part no | 定位器标签号                     | 4 bytes |                   |
| 厂商信息      | Manufacturer                     | 2 bytes | 昂科固定0x00 0xff |
| 携带数据      | Manufacturer Data                | 12bytes | 最后一位为seq     |
| RSSI          | 定位器收到该蓝牙的信号强度       | 1 byte  | 有符号 -128到127  |
| 采集时间      | 可以使用引擎接收到数据的时间来做 | ---     | 软件部决定        |
