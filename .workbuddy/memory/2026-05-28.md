# 2026-05-28 工作日志

## 修复图片不显示问题

- 文章：`_posts/2025-05-27-A1 系列蜂巢基站.md`
- 原因：图片路径为 Windows 绝对路径（`C:\Users\...`），Jekyll 无法识别
- 修复：
  1. 将图片从 `_posts/assets/` 复制到 `assets/posts/`（Jekyll 能正确打包的目录）
  2. 将 Markdown 中的路径改为 `{{ "/assets/posts/image-xxx.png" | relative_url }}`
- 约定：以后文章图片统一放在 `assets/posts/`，引用格式用 `relative_url` filter
