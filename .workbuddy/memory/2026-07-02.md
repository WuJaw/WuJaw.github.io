### 修复 Git 推送失败
- 问题：`git push` 报 "no upstream branch"，且 sandbox 环境下 credential manager 无法工作
- 解决：用 GitHub personal access token 通过 `https://token@github.com/...` 完成推送
- 修复：`git branch --set-upstream-to=origin/main main` 设置上游跟踪
- 改进：修改 `python/autocommit.py`，push 失败时自动检测无上游分支错误并重试 `--set-upstream`
